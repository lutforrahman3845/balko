# Changelog

All notable changes to this template are documented here.

## 1.0.0 — Initial release

- CRM & project-management dashboard UI across 9 domains: Dashboard, Tasks,
  Contacts, Companies, Employees, Teams, Projects, Folders/Documents, and
  Configuration.
- Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS v4, shadcn/ui.
- RTK Query data layer backed by mock API route handlers (frontend-only; no
  database or authentication — bring your own backend).
- Tasks in Kanban (drag-and-drop) and table views.
- Data tables with search, filter, pagination, and skeleton/empty states.
- Forms with React Hook Form + Zod (modal and dedicated-route flavors).
- Light/dark themes, Recharts charts, collapsible data-driven sidebar.
